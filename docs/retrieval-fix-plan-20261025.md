# 检索优化计划：语义召回 G3 0.30 → 0.85（2026-10-25）

目标：freeze hybrid semantic Recall@5（G3）从 0.30 提到 **≥ 0.85（20 题中 17）**，G4（Neg@5 ≤ 0.20）与 G1–G11 其余门槛不回退。

**本期不改题集与标注**（2026-10-25 已定）。标注审计（`tools/audit_semantic_gt.py`）确认 20 题零硬伤：期望页全在、验收短语全能在期望页复核、问句年份与文档年全部一致、FTS 0/20 命中（无词汇泄漏）。0.30 的账记在检索侧。

**2026-10-25 回放复核**（无硬过滤；公司 + 问句年份过滤；当前使用文档 `live_report_sql`、`is_ocr<2`；按向量距离聚合到页）：20 题的期望页名次与含短语页名次已逐题量出，见 §12，与外部复核一致。带硬过滤的手工复现为 5/20，差在 020（含短语页名次约 5–6，边界题；差异归因于评测链路的 200 块窗口与 FTS 分路）——**把复现钉死到官方 6/20 是 P0 的验收条件**。

**根性结论**：`vector_search` 的实体约束同时承担「G8 无答案安全」和「相关性过滤」两个方向相反的职责。语义题的定义就是问句不用答案页的词，于是多数被它淘汰；而无答案题（火星/比特币）恰好又靠它保持空。**先拆职责，再谈排序与模型。**

**规则骨架**：

1. **实体抽取重做**：名词连续段不拆（欧洲门店数量、购物中心、低线城市），剥副词/动词/代词性词缀（上/实际/将来/大概/肯/主动/交给/去…时/叫/起过/种/套/名字/称呼）。产出实体词（硬判定 + 软权）与口语残片（弃用）。
2. **库外实体预检**：实体词非空且**全部**在公司语料 0 命中 → 返回空；实体词为空 → 不预检；mixed（部分命中）→ 默认不空。
3. **验收线**：noans ≥ 7/8 空（门槛 empty_rate ≥ 0.75，8 题里 6/8=0.75 贴线过，**余量 2 题**；阶段目标 ≥7/8——noans-006 已确定为用掉的那 1 题，003 必须靠抽词规格守住）；freeze + diag 语义**误空 = 0**。
4. **mixed 规则先不定稿**：noans-006 的瑞幸页已按文档年列出（见上表），年份盖不住、实体又在库——骨架内不存在能守住它而不误空语义题的规则。结论按确定结果写：noans-006 会返回页、接受 7/8，不硬造规则。

**抽词规格样例（1a 验收样本，不是改题）**：问句「百胜中国欧洲门店数量」的硬实体列表必须只保留「欧洲门店数量」，不得另留「欧洲」。实现后用 `diag_needle_coverage.py` 打印这条列表；打印结果含「欧洲」时，预检规则先不合并。

**预检合并条件**：对硬验收集合 002、005、008、011、014、016、018 打印新实体列表。某一题因新抽词会被判空的，该题按「实体词为空、不预检」处理，不得带着它被判空的状态把预检合并进 `hybrid_search`——这是「freeze 与 diag 语义误空 = 0」的操作定义。打印通过后，预检才进入 `hybrid_search`。

**004 二选一（已定）**：预检**不判空**（依据：名词锚「客人」在库 189 页，mixed → 放行，嵌入模型仍能看到这题）。004 留在 `questions.yaml` 和回归分母 n=20 里；本期不安排步骤指望它翻绿（含短语页名次 547，任何重排窗口外）；换模型之后若它进入前 5，仍算进 17/20。不从题集或分母里删除。

### 1b 实现（1 天）

- `stock_kb/search.py`：新增实体段抽取与库外判定；`claim_needles` 保留仅作诊断对照。
- `stock_kb/vector.py`：`vector_search` 去掉 `_content_has_needle` 硬过滤；`hybrid_search` / `vector_search` 入口先跑库外实体预检 + 现有年份/公司判定。
- **软权 λ 只作用于 1a 抽出的实体词**，不作用于现行 `claim_needles` 字符串（其中含全库 0 命中的口语残片，也含「名字」「经营」这类高频词，加权会扰乱排序）。
- **λ 的单位**：融合分数是 RRF（`rrf_k = 60`），第 1 名只贡献 1/61 ≈ 0.016。把常数直接加到 RRF 总分上（任何 ≥ 0.02 的常数都会让词面命中主导排序），002 第 1、005 第 3 不再成立。软权公式只允许「命中实体词的那一路 RRF 项乘以 (1+λ)」或「加上不超过 1/61 的常数」。**P1 里程碑只认 λ=0 那一次回归**；λ>0 的软权实验单独一次回归，不替代里程碑。
- **011 的守成通道**：备用查询不是通用规则，**名单初值只有「突破」**（语料 58 页），在整句 FTS 为空时进入 FTS 分路。「突破」两字走 LIKE（短于 3 字不走 trigram AND，LIKE 为空才走 bigram）——备用查询的验收是**融合后的前 5 仍含验收短语「突破3万家」的页**，不是「LIKE 返回了页」。011 问句无年份，2022 年同样写着「突破」的页允许出现，只要短语页仍在前 5。
- **名单扩充规程**：1a 用 `diag_needle_coverage.py` 打印每个实体词的命中页数。某个词要加入名单，先在打开该词之后重测 002 与 005——002 可能抽出「购物中心」这类高频词，以全文检索第 1 名进入 RRF，把现在排第 1 的页挤出前 5——两者仍在前 5 才保留该词。通道只加在 hybrid 融合路径，不改 keyword 的短查询短路（G1/G2 安全）。
- MCP `search_reports` 零命中升级路径行为随之变化：跑 `tools/test_mcp_http.py`（stdio 顺手验一次）。

## 5. 阶段 2：候选池加深（1 天）

- 代码路径：改的是 `hybrid_search` **内部的候选页数**，不是评测的 k。`tools/run_eval_regression.py` 与评测的 `top_k=5` **不要改**，Recall@5 仍用这个 5。在评测 top_k 仍为 5 的前提下，把 `candidate_k = max(top_k*4, 20)` 提到能取出 50 页（例如 `max(top_k*4, 50)`）；`vector_search` 因此得到 `top_k=50`，有公司过滤时 `chunk_limit = 50×10 = 500` 块；hybrid 返回给评测的仍是融合后的前 5 页。池子只改变第 6 名及以后是否被取回，**不改变前 5 成员**（排序键不变时）。
- FTS 分路为空时的处理与 P1 最终配置相同：λ=0；整句全文检索为空时，只走已验收的备用查询；再按现有 RRF（`rrf_k = 60`）融合；评测仍切 `top_k = 5`。不把软权加进这一步的排序键，也不写成「直接返回原始向量页序」——那会把 011 的词面通道清掉。
- **通过条件**：013(18)/017(20)/015(36)/012(38) 的含短语页进入重排输入——按 P0 末列核对**含短语页最近块的全库序号 ≤ 500**；某题 >500 时记「50 页候选仍取不到」，不把失败记到重排器头上。Recall@5 预期与 P1 相同。
- noans-003 由复合段预检守住（「欧洲门店数量」全库 0 页）。003 也返回页时，与 006 合计 6/8：G8 的 empty_rate ≥ 0.75 贴线过，但阶段目标 ≥7/8 **失败**——不得写成「接受 7/8」。

## 7. 阶段 4：更强模型与重排器（约 3 天）

### 4a bge-m3（已在 `models/`）

- **窗口按页名次写，且只对当前 §12 表有效**（换前缀或换模后以重打的新表为准）。前 50 页目标只含含短语页名次 ≤ 50 的题：**003(8)/006(9)/007(6)/010(12)/013(18)/017(20)/015(36)/012(38)**，以及需要守住的 011、020。001(107)/009(106) **不写入** 50 页目标；要把它们列入，窗口至少约 **120 页**，单独实验并记录延迟（按文本块记，不按整页）。**停止线：含短语页没进前 5 就停，不把窗口加宽到 200。** 019(187)/004(547) 不进重排目标。

### 4c 重开分块实验（条件触发）

- 仅当 4b 的两步便宜实验——001/009 的至少 120 页重排实验（含短语页没进前 5 即停）与 019 的同文件 ±3 邻页实验——都已做完、结果仍 <17/20 时才重切块。这两步没做完，不要执行 `index --rebuild-chunks`：该命令**清空所有模型的向量**，包括刚建的 bge-m3（做过 4a 后，4c 完成两个模型都要重嵌）。执行时备份 DB → `embedding.chunk_size` 800→400 → `index --rebuild-chunks` → 回归。
