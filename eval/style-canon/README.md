`PLAN.md` §9 与 `skill/stock-note/templates/note_template.md` 按《中国金茂笔记》列了 13 节。这篇样稿是 **安井食品（SH603345）扫描**，章节是：

2. 产能情况
3. 利润情况（含图）
4. 公司销售分产品情况（含图）
5. 资产负债情况（含图）
6. 现金流量情况（含图）
7. 行业情况 / 速冻菜肴行业发展情况
8. 同行对比（两句）
9. 未来看点（3 条）
10. 总结（竞争力 + PE/股息率）

| 维度 | 这篇雪球扫描 | 仓库金茂模板 |
|---|---|---|
| 开篇 | 无「一句话结论」，标题即扫描 | 要求一句话结论 |
| 口气 | 第一人称判断（「我认为非常好」「泼一瓢冷水」） | 组稿路径故意不写观点 |
| 数字出处 | 无「《文件》第 N 页」 | 产品承诺必须文件+页码 |

| 估值 | 总结里 17x PE + 派息率 70% → 股息率 4–5% | 独立「估值推演」+ 情景假设 |
| 同行对比 | 经销商收入、净利率两句 | 2–3 个维度、带来源 |
| 配图 | 多张自制表/图 | 模板以 Markdown 表为主 |
| 篇幅 | ~3300 字 | 1,500–3,000 字 |
