## 2. 写法上的稳定习惯

1. **开篇不写总判断。** 标题即任务（扫描/笔记），第一屏是股票标签，然后直接进股东或利润表。
2. **报表节几乎都配图。** 利润、资产负债、现金流后面空段，对应自制表。文字是图的解说，不是把表再抄一遍。
3. **净现金会写公式。** 华域：货币资金 − 短期借款 − 一年内到期非流动负债 − 长期借款；并注明未计入哪些可变现资产。
4. **解释「毛利率掉了但净利率升了」这类矛盾**（安井：运费入成本 + 物流半径；华域：竞争压利润率）。
5. **业务问题做成小标题**，不是全塞进「经营情况」一大段（露露：南方为什么少；特钢：是不是成本定价；海尔：卡萨帝 / 三翼鸟 / 海外）。
6. **第一人称判断留在节内**：「我认为非常好」「泼一瓢冷水」「这个扣除没有多大意义」。不单独开「观点」章。
7. **收束几乎总是：当前 PE、派息率、股息率，再加 1–2 个「如果没增长 / 如果恢复到某利润」的情景。** 金茂把情景写得最完整（销售额 × 净利率 × 权益比例 → 归母 → 股息）。不是 DCF 大表，也很少单独「估值推演」章（特钢是例外）。
8. **同行对比很薄**：两三个指标（经销商收入、净利率、ROE、海外占比），不写长对比表。
9. **数字没有「《文件》第 N 页」。** 金茂有一处「克尔瑞点评（来源链接）」，其余默认读者信作者读过财报。这和 stock-kb 的产品承诺冲突，模板可学结构，出处不能学。

## 3. 建议 skill 用的扫描体（带出处）

给 `stock-note` 用的是「结构学专栏、纪律用知识库」，不是逐字模仿。

```markdown
# {公司}扫描

$本公司(代码)$  $同行1$  $同行2$

## 股东及高管
{实控人、管理层持股是否覆盖年薪}  《文件》第N页

## 利润表
{收入是否连增、利润拐点、毛利率/净利率及原因}  表 + 出处

## 分产品或分地区
{有则写；没有就「暂无数据」}

## 资产负债
净现金（写公式）/ 应收应付 / 商誉与减值 / 资本开支    出处

## 现金流与分红
自由现金流、派息率路径、近年分红金额    出处

## 行业与同行
{空间、集中度、2–3 个可核对指标}    出处；没有研报就少写

## 未来看点
1. …
2. …
3. …     能核对的写出处；情景假设标明是假设

## 总结
1. 生意质量（只复述上文已引用的事实）
2. 估值：PE、派息率、股息率；情景与不确定性
3. 要盯的风险（有出处写出处；判断句单独标成判断）
```

相对仓库金茂 13 节模板：去掉开篇「一句话结论」硬性要求；「研报观点」并进行业节，没有研报就空；「估值推演」并进总结，用 PE/股息率而不是大情景表；「风险」可独立也可进总结。财务摘要表仍可作为利润表节的 Markdown 表，每格带 locator。

组稿路径 `compose-note` 已按上列顺序出 Markdown 与 HTML（SVG 图）；空节写「暂无数据」。关键数字强制 `《文件》第N页`。
