## 1. 取数清单（写前必集——「数据翔实」的来源保证）

### 1.1 公司与行情
- 主营业务一句话概括；发展历程 2–3 个关键节点（成立/上市/重大并购/转型）
- 实控人及穿透比例、管理层持股与薪酬、股权激励条款与门槛、增减持、大股东质押
- 股价、市值、币种（B 股/港股注明）；PE(TTM) 与历史估值区间；股息率；上市与再融资史（IPO/定增/配融金额）

### 1.2 利润表（近 3–5 年逐年 + 最新季度）
- 营收及增速（逐年；可拆季度）；归母净利、扣非净利及**差异逐项拆解**（政府补助/公允价值变动/减值转回/处置资产）
- 毛利率、净利率序列与拐点归因（原材料/油价/汇率/产能利用率/结构变化四个高频原因）
- 四项费用率序列；分产品/分业务/分地区收入与毛利率；产能利用率（销量/产能）
- 客户集中度（第一大/前五大占比）、供应商与原材料成本结构

### 1.3 资产负债表（最新期 + 趋势）
- 货币资金、短期借款、一年内到期非流动负债、长期借款 → **净现金 = 货币资金 − 短期借款 − 一年内到期非流动负债 − 长期借款**
- 净现金「打折」三件套：受限资金、票据质押、存放关联财务公司
- 应收账款（金额/账龄/坏账计提比例/第一大客户占比）；应付 vs 应收（产业链占款能力）；存货与合同负债（订单先行指标）
- 固定资产 + 折旧年限（= 固定资产 ÷ 年折旧）；在建工程（达产后固定资产/产能弹性）；商誉及减值史；无形资产构成；长期股权投资（投资收益 ÷ 账面 = 回报率）
- 资产负债率、ROE（有失真要解释，如合同负债/黄金租赁抬高的负债率）

### 1.4 现金流与分红（区间越长越好，5–15 年）
- **累计五件套**：累计经营活动现金流净额、累计净利润、累计资本开支、累计自由现金流、累计分红
- FCF/净利润（= 理论最大派息率）；分红率逐年序列与承诺原文；回购金额与注销比例；分红 vs FCF 的关系（是否负债分红）

### 1.5 行业与同行
- 行业规模与增速（CAGR）、集中度（CR5）与公司份额/排名；人均消费量或渗透率的国际对比（消费行业）
- 同行 2–3 家 × 2–3 个指标（净利率/毛利率/ROE/份额/成本/单厂效率）

### 1.6 行业专属数据（按公司挑选，做成本篇的「专属节」）
- 周期资源品：产品价格走势与历史区间、单位价格弹性（每涨 1 万元/吨 × 权益产能 = 毛利增量）
- 电力：煤价/电价**双向敏感性测算**、装机结构与在建投产节奏、利用小时数
- 消费品：量价拆分（销量/均价）、渠道与经销商数量变化、门店数、新品类进展
- 制造业：产能扩张计划金额与投产时间、单位投资产出、原材料占成本比
- 金融/地产：减值计提与拨备、土储/项目明细、融资成本
- 高速/公用：路产里程与收费期限、改扩建资本开支测算

## 2. 章节骨架与逐节写法

**固定顺序**（★=几乎每篇必有；☆=按公司特性取舍）：

> ☆公司简介/发展历程 → ☆股权与管理层 → ★利润表（+☆费用率/分业务/分地区）→ ★资产负债表（逐科目小标题）→ ★现金流 → ★分红（回购）→ ☆财务摘要 → ☆行业 → ☆同行对比 → ☆未来看点 → ★总结

排序允许的变体：资产负债表可前置（福耀、景津扫描）；「分红及估值」可合并收尾（景津扫描）；跟踪笔记可行业开头（京能）。**总判断永远在最后**。

### 2.1 ☆公司简介 / 发展历程 / 股权与管理层
- **必备**：主业一句话；历程 2–3 节点；实控人穿透比例；高管持股/薪酬/激励
- **写法**：开篇即事实陈述，不写导语、不写评级；股权结构是全文第一个高频判断位（治理好坏直说）；管理层薪酬/治理瑕疵顺手指出的同时给定性
- **例句**
  - 「这个股权结构我认为非常好，既有大股东帮小股东盯着这些管理层；管理层又有足够的股份，起到了非常好的激励作用。」（安井）
  - 「王老板给自己开的薪资500多万，其他管理层薪资都不超过50万，这算一个小瑕疵吧。」（凌霄泵业）

### 2.2 ★利润表（全文重心，篇幅最大）
- **必备**：营收逐年+最新季度拆分；归母/扣非拆解；毛利率净利率序列；四项费用率；分业务毛利率；产能利用率
- **写法**（按序）：
  1. 收入长期趋势一句定性 → **逐年归因链**（每一年贴一个因果标签）
  2. 最新季度增速拆分（Q1/Q2 分开），收入与利润并排
  3. 利润与收入背离的机制解释（「利润波动大于收入，这是周期制造业通病」式）
  4. 毛利率/净利率拐点归因；**会计准则变更还原**（运输费重分类、质保费等：「剔除这个影响，毛利率仅仅小幅下降约 0.5%」）
  5. 扣非差异逐项拆（补助 X 亿 + 公允价值 Y 亿 + 转回 Z 亿）
  6. 产能利用率收尾（「接近 100%，预计短期内销量对业绩拉动很小」）
- **例句**
  - 「24，25年的增长速度有所下降，但是26年上半年收入增速又回到了21.9%。拆分来看一季度增长30.8%，二季度增长13.8%。」（安井）
  - 「财务费用：从2018年25.4亿元减少到25年的2.9亿元，7年间，仅仅财务费用，就增厚了22.5亿元税前利润。」（云天化）
  - 「25年归母净利润6亿元，扣非归母利润4.2亿元，这中间的非经常性损益主要是政府补助0.89亿元，公允价值变动0.51亿元，应收账款转回0.52亿元。」（精工钢构）

### 2.3 ★资产负债表（逐科目小标题，**金额直接写进标题**）
- **必备**：§1.3 全部科目；重点是净现金、应收、存货+合同负债、固定资产、商誉
- **写法**：
  1. 科目即小标题（`净现金232亿元：`、`应收账款505亿元：`、`商誉：273亿元`）——读者扫目录即得资产负债表主干
  2. 每个科目「金额 + 一句为什么」（良性/恶化/会计原因/行业惯例）
  3. 净现金必写公式，并做**打折检查**（受限/质押/关联存款）
  4. 固定资产配折旧年限心算；在建工程配达产后弹性推算；合同负债当订单先行指标（失效也要说）
  5. 应付 vs 应收 → 产业链地位一句话
- **例句**
  - 「这65.8亿元货币资金中有约40亿元是开具应付票据的质押资金，所以公司的净现金状况是要打折扣的。」（精工）
  - 「按可采储量计算，吨煤估值约23.5元/吨……对应25年的估值13倍PE。」（鄂尔多斯，收购估值类比）
  - 「25年公司的利息收入0.5亿元，账面40亿的货币资金，利息收益率只有1.25%左右，这个收益率大幅拉低了公司的ROE。」（航民）

### 2.4 ★现金流（累计五件套是签名式写法）
- **必备**：累计五件套（§1.4）；FCF/净利润；分红 vs FCF 关系
- **写法**：模板句起段（区间 5–15 年）→ 一个比值定性（FCF/净利 = 理论派息上限）→ 追问差值或异常（净现金变动与净利对不上？分红靠借款？）
- **模板句**（逐字学这个结构）
  > 「统计{公司}{YYYY–YYYY}年累计的现金流情况，累计实现经营活动现金流净额{A}亿元，累计资本支出{B}亿元，累计净利润{C}亿元，累计自由现金流{D}亿元，累计分红{E}亿元。」
- **例句**
  - 「统计2010年-2026H1的现金流情况，累计实现经营活动现金流净额1368亿元，累计净利润1214亿元，累计资本开支702亿元，累计分红358亿元。经计算，累计自由现金流666亿元。」（华域）
  - 「公司的分红实际来源于银行的借款。」（国电电力——FCF 为负时分红的来源追问）

### 2.5 ★分红（回购）
- **必备**：分红率序列与承诺原文；累计分红 vs 累计利润/FCF；回购注销金额 vs 市值；现算股息率
- **写法**：**意愿 vs 能力两分法**是签名框架；治理点评顺带给（「抠抠搜搜」「大大的点赞」）；B 股/港股高股息要点明
- **例句**
  - 「我经常讲的一个公司看他的分红，从两个方面，一是看分红意愿，二是看分红能力。两者缺一不可。」（精工）
  - 「只有分红态度+分红能力都没问题，才可以把承诺的分红当成最终的分红。如果公司经营情况有问题，即便再强的意愿都没用，典型的例子就是：洋河股份。」（伊利）

### 2.6 ☆分业务 / 分产品 / 分地区（多业务公司几乎必有）
- **必备**：各业务收入、占比、增速、毛利率；国内外拆分；客户集中度
- **写法**：占比排序叙述（「占比最大的是X……其次是Y」）→ 每块业务一句定性 → 低毛利业务放量拉低整体毛利率这类结构效应要点出
- **例句**
  - 「25年，占比最大的是硅铁，25年营收89亿元，占比34.6%；其次是PVC树脂，占比17%。」（鄂尔多斯）
  - 「2024 年第一大客户销售额占比 13%，前五大客户占比为 46%，公司对单一客户的依赖性并不强。」（超盈）

### 2.7 ☆行业（成长股写透，成熟股可省并明说）
- **必备**：规模+CAGR；人均/渗透率国际对比；CR5 与公司份额；子行业增速结构
- **写法**：空间 → 集中度 → 公司位置（是第几梯队、份额是第二名几倍）；**必配一段泼冷水**（门槛低/非标/分散/政策变量）
- **例句**
  - 「从2019年的1265亿元升至2024年的2212亿元，CAGR约11.8%」「人均消费量……美国为 62.6 千克、英国为 45.9 千克及日本为 25.3 千克」（安井）
  - 「但是我也要泼一瓢冷水，这个行业看着市场很大，但是门槛低，产品非标，所以行业也非常分散。」（安井）

### 2.8 ☆同行对比（**点到为止**）
- **必备**：2–3 家 × 2–3 个指标（净利率/毛利率/ROE/份额/成本）
- **写法**：独立节仅两三句，或内嵌各节；差距必给归因（成本？配套？品牌？）
- **例句**
  - 「公司单个经销商的收入远高于同行。净利率高于同行。」（安井——全节就两句）

### 2.9 ☆未来看点 / 未来的增长（**问题做小标题**）
- **必备**：2–4 条；每条能核对的给数据，情景假设标明假设
- **写法**：小标题用疑问句（「越南新增产能能否被消化？」「水系列能否成功？」）；「先说结论：……」开头直答，再给依据
- **例句**
  - 「先说结论：是的，大概率会导致毛利下降（最近一段时间股价下跌，市场大概率也是在交易这个预期）。」（超盈）

### 2.10 ★总结（收束公式，全篇唯一可给结论的地方）
- **结构**：编号清单（1）定性（2）估值（3）风险/不确定性，末条常是「边走边观察」
- **估值收束公式**：当前 PE × 派息率 → 股息率，再给 1–2 个条件句情景（「如果增长……如果没有增长……」）；自由现金流型公司可用（EV/FCF）；判定词梯度：**低估 > 尚可/合理但不低估 > 鸡肋**；可给仓位态度（「仓位控制在 3% 以内」「有闲钱可以适当配置」）
- **纪律**：毛估估必须当场亮算式并自我降级（「这个是毛估估」「千万不要直接拿这个预期来作为买入的理由」）；假设越多越要打折
- **例句**
  - 「（2）估值方面，当前17倍PE，如果今年业绩能够20%增长，按照派息率70%，公司的今年预期股息率在5%左右，如果没有增长，股息率略高于4%。17倍的估值已经包含了成长的预期，如果公司未来失去了成长性，那么17倍估值就有些高了。」（安井）
  - 「毛估估25年利润20亿左右，对应公司目前约160亿市值，50%的分红率，25年股息率大概是6.25%。……让自己心里有个数。」（建投能源）

## 3. 贯穿全文的十条写法规则

1. **开篇零铺垫**：标题即任务，第一屏进股东/简介；总判断与估值只出现在总结。
2. **数字写进叙述**：用「从 X 到 Y」「在 Z 年达到峰值后回落」的趋势句和逐年归因链，把报表曲线翻译成事件史；表格只做出处与汇总，正文不复读表格。
3. **三明治句**：每个数字后跟归因或影响；不裸奔数据。
4. **现场心算**：折旧年限（固定资产÷折旧）、存款利率（利息收入÷存款）、单位弹性（涨价×产能）、股息率（每股分红÷股价）——把除法当场做给读者看，这是本体裁最有辨识度的动作。
5. **会计口径侦探**：准则变更还原、净现金打折（受限/质押/关联存款）、扣非逐项拆、一次性损益剔除——先修口径再下判断。
6. **第一人称判断直给**：「我认为」「我倾向于」「这算一个小瑕疵」；同时留余地（「大概率」「边走边观察」），推测必须声明是推测。
7. **疑问句做小标题**：业务疑问（「为什么货币资金40多亿，短期借款还有20多亿？」）与看点（「越南新增产能能否被消化？」）都写成问题，节内「先说结论」。
8. **出处随手点名**：年报/业绩会/研报/机构数据点名；用 AI、他人表格、毛估估要声明（「数据来源于deepseek，如果有错误，欢迎球友指出」）。
9. **同行对比薄**：两三个指标足矣，差距给归因，不写长对比表。
10. **按需省略并明说**：成熟股可不写行业（「所以这篇文章我把行业部分的分析也省略掉了」）；行业专属节（敏感性测算/装机/路产/产能）按公司类型插入。

## 4. 发布前自查清单（LLM 生成后逐条过）

- [ ] 开篇没有总判断/评级？结论只在总结？
- [ ] 利润表、资产负债表、现金流、分红四节齐全且顺序正确？资产负债节是否逐科目小标题？
- [ ] 累计现金流五件套写了？FCF/净利润比值给了？
- [ ] 有没有连续 3 个以上数字没被解读？每个判断是否都有上文数据支撑？
- [ ] 至少 2–3 处现场心算？准则变更/一次性因素还原了吗？
- [ ] 净现金做过打折检查？扣非差异拆过？
- [ ] 第一人称判断 ≥3 处且留了余地？推测都声明了？
- [ ] 总结是「定性 + PE×派息率→股息率 + 情景 + 风险」？毛估估带免责？
- [ ] 数据都有来源或标注「未取得」？估算/AI 统计声明了？
- [ ] 篇幅 1,700–3,800（复杂可放宽），无复读、无注水？

## 5. 反模式（出现即不合格）

- ❌ 开篇「一句话结论」、评级（买入/增持）、目标价——这是研报体，不是扫描体
- ❌ DCF 大表、精确到分的盈利预测——本体裁只做毛估估并当场亮算式
- ❌ 表格复读：把财报数字原样搬进正文而不解读
- ❌ 无出处数字、把估算当事实、编造行业数据
- ❌ 每节硬凑一条判断（没观点的节就只给事实），或通篇无判断（那是数据摘录不是扫描）
- ❌ 长篇同行对比表、面面俱到的百科式介绍
- ❌ 绝对化表述（「必将」「肯定翻倍」）——判断永远留余地
